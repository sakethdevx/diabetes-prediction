# Datasets Branch

This branch is dedicated to the project data assets only.

## Contents

- `NHANES dataset/`: source CSV files used to build the combined dataset
- `pima dataset/`: PIMA diabetes data
- `combined_diabetes_dataset.csv`: merged dataset used for analysis or modeling
- `merge_datasets.py`: script used to combine the source datasets
- `dataset_description.txt`: summary of the merged dataset and columns

## Purpose

Keep this branch focused on data storage and dataset preparation so the application code remains on `main`.
